The likely integration point is the network/file image error builders in `lib/src/common_widgets/cover_art_image.dart`, with classification/recording in the recovery/cache-manager path. Kept unannotated, with baseline reason `suspected missing call: image codec failures are not emitted as decodeFailure`. No call is added.

They are not missing production flows. EQ gesture calls likewise use the graph-session API.
