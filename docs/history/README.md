# Historical documentation

This directory records material removals, deprecations, and replacements that
future contributors would otherwise have to reconstruct from Git history. It is
not an archive of every prior document; active documentation remains the guide
to current behavior.

Use [removed-features.md](removed-features.md) for user- or architecture-visible
retirements. Add a record only when the prior behavior, migration, or reason is
important to future maintenance. Include evidence links or commit IDs when
known; use `YYYY-MM-DD` dates and write `unknown` when evidence is absent.
