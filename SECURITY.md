# Security policy

## Supported versions

Only the latest stable release of Navis receives security fixes.

## Reporting a vulnerability

Report privately. Do not open a public issue.

- GitHub: Security tab › Report a vulnerability (private vulnerability reporting) at https://github.com/Porthorion/Navis/security
- E-mail: support@porthorion.com

Include the Navis version, platform, and steps to reproduce. You should get an acknowledgement within 7 days.

## Scope

In scope: the shipped apps (Android, Windows and Linux builds) and their update channel.

Out of scope: developer and diagnostics tooling (`tool/`, the profile-build diagnostics server, local signing and release scripts). These are for local use and are intentionally lightly protected; see [the security audit](docs/audits/security-audit-2026-10-09.md).
